## Özet

As of August 2026 the honest answer for a solo operator is: you do not need an agent framework. The Claude Agent SDK (TS + Python, `@anthropic-ai/claude-agent-sdk` / `claude-agent-sdk`) is now a full agentic runtime — subagents (nested, forwarded in the stream via `parent_tool_use_id`), hooks (~25 events incl. `PreToolUse`, `PermissionRequest`, `SubagentStart/Stop`, `TaskCreated/Completed`), MCP client, permissions, JSONL sessions on disk with `resume`/`fork`/`listSessions`, `--json-schema` structured output, and plugins that bundle skills+agents+hooks+MCP servers. Claude Code itself is a programmable runtime (`claude -p --bare --output-format stream-json`) callable from any language. Skills are now an open spec at agentskills.io (stewarded via the Agentic AI Foundation) — a plain `SKILL.md` folder that also runs in Codex, Copilot, Cursor, Gemini CLI. That combination is exactly the git-backed brand-system-as-code the user wants: brand rules become Skills, product knowledge becomes files, channels become subagents.

Human-in-the-loop has a first-class answer now: the `AskUserQuestion` tool + `canUseTool` callback pauses the agent indefinitely (Claude generates 1–4 questions with 2–4 options each — literally "pick one of 3 angles"), and the `defer` hook decision lets the process exit and resume later from the persisted session. MCP's Tasks extension (spec 2026-07-28) adds durable handles, `input_required` status and `tasks/update` for long media jobs — the right shape for "video render takes 8 minutes".

The framework layer (LangGraph, Mastra, CrewAI, ADK 2.0, Pydantic AI, OpenAI Agents SDK) is mature but mostly redundant here; Mastra and LangGraph earn their place only if you want typed graphs with checkpointed suspend/resume. For durable execution one person should use Postgres, not a cluster: pg-boss or Graphile Worker (both MIT) beat Temporal/Restate/Hatchet on operational cost. Trigger.dev v4 (Apache-2.0, real self-host) is the DX sweet spot if you want a UI. Langfuse (MIT core) is the default observability layer. Watch licences: n8n SUL, Restate BSL-1.1, Inngest server SSPL, Phoenix ELv2, ComfyUI GPL-3.0. Flowise was archived on 2026-08-13.

<details><summary>Notlar</summary>

**Claude Agent SDK (TypeScript)** — Governed by Anthropic Commercial ToS, not OSS. claude.ai OAuth login is NOT permitted for third-party products — use ANTHROPIC_API_KEY. Branding rules forbid calling your product 'Claude Code'. The experimental V2 session API (createSession) was REMOVED in 0.3.142 — use query() + resume.

**Claude Agent SDK (Python)** — Gotcha: `can_use_tool` requires streaming mode, and with a finite prompt generator the input stream closes before the callback fires — you must register a dummy PreToolUse hook returning {'continue_': True} to keep it open. `updated_permissions` needs claude-agent-sdk >= 0.1.80.

**Claude Code headless mode (`claude -p`)** — `--bg` and `--cloud`+task-description are rejected with -p. Piped stdin capped at 10MB. Background bash killed ~5s after result; background subagents waited on, capped 10 min (CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS). Without --bare it executes hooks and MCP servers from an untrusted repo's .claude/settings.json — use --bare in automation. SIGTERM exits 143 after running SessionEnd hooks.

**Agent Skills specification (agentskills.io)** — Progressive disclosure: name+description (~100 tokens) always loaded, body loaded on activation (keep <500 lines / <5000 tokens), references loaded on demand. `name` must match parent dir, lowercase, no consecutive hyphens. Portable to Codex/Copilot/Cursor/Gemini CLI, so no Anthropic lock-in on your knowledge base.

**Claude Code Plugins + marketplaces** — Directories go at plugin ROOT, not inside .claude-plugin/ (most common mistake). Plugin skills are namespaced `/plugin:skill`. `monitors/monitors.json` gives you a background watcher (e.g. tail a render log) that notifies Claude without you prompting. Private marketplace = private GitHub repo.

**AskUserQuestion + canUseTool (HITL primitive)** — HTML previews are perfect for 'here are 3 post layouts' cards in your command center. NOT available inside subagents spawned via the Agent tool. Callback never fires for tools auto-approved by an allow rule or acceptEdits — use a PreToolUse hook if you need to see every call. Free-text 'Other' is supported by putting the user's text in answers[question].

**Hook `defer` decision (long pauses)** — UNVERIFIED in detail: the user-input page links to /docs/en/hooks#defer-a-tool-call-for-later but my fetch of the hooks page did not surface the field schema. Confirm before relying on it; fallback is to persist state yourself and start a fresh session with the answer in the prompt.

**Claude Managed Agents (beta)** — Stateful by design so NOT eligible for Zero Data Retention or HIPAA BAA. MCP tunnels and 'dreaming' are a narrower research preview requiring a request form. Scheduled deployments could replace a cron+VPS for the weekly content calendar.

**Anthropic Structured Outputs (Messages API)** — GA, not beta. Supported on Opus 5/4.8/4.7/4.6/4.5, Sonnet 5/4.6/4.5, Haiku 4.5, Fable 5, Mythos 5. NO recursive schemas, no minimum/maximum, no minLength/maxLength, minItems only 0 or 1, additionalProperties must be false. First call with a new schema pays grammar-compile latency (cached 24h). Changing the format invalidates the prompt cache. Param moved from `output_format` to `output_config.format`.

**Anthropic Message Batches API** — Max 100,000 requests or 256MB per batch. Most finish <1h; hard expiry at 24h (expired requests are not billed). Results downloadable for 29 days from created_at. max_tokens:0 cache pre-warming unsupported inside a batch. Not compatible with Fast mode.

**Anthropic prompt caching** — Cache invalidates if you change output_config.format mid-conversation, or edit any byte of the cached prefix — so keep the brand prefix stable and put volatile stuff after the breakpoint.

Spec explicitly says tool descriptions from untrusted servers must be treated as untrusted input.

**MCP Tasks extension** — `input_required` + `inputRequests` gives you human approval INSIDE a tool call, resolved via tasks/update — a second HITL pattern alongside AskUserQuestion. Cancellation is cooperative (server may ignore). Host support varies; check the client matrix. Persist task IDs durably.

**LangGraph** — 39.7k stars. `interrupt()` + a durable checkpointer + thread_id is the cleanest OSS pause/resume in Python if you ever outgrow sessions. ### Öneriler

- Build the spine out of the Claude Agent SDK plus MCP and skip the framework layer entirely: a single git repo where `skills/` holds the brand voice, visual rules and product knowledge as SKILL.md files, `agents/` holds one subagent per channel (instagram, reels, linkedin, demo-video, deck, ads), and `.mcp.json` wires in the connectors — this is version-controlled, diffable, portable to Codex/Cursor/Gemini, and needs no orchestration library at all.
- Implement the 'agent proposes 3 angles, you pick one' loop with the built-in AskUserQuestion tool and a canUseTool callback rather than inventing your own approval protocol — Claude generates 1-4 questions with 2-4 labelled options, your callback blocks indefinitely until you answer, and on TypeScript you can set toolConfig.askUserQuestion.previewFormat='html' so each option arrives with a rendered visual preview you can show as a card in the command center.
- Make the job layer pg-boss on the Postgres you already need for the command center: it gives cron for the weekly content calendar, exponential-backoff retries for flaky media APIs, dead-letter queues so a failed render is visible rather than lost, and it is MIT with no enterprise split and no second stateful service to back up — reach for Trigger.dev v4 (Apache-2.0, real self-host, no task timeouts, proper run UI) only when you want a dashboard over multi-minute video jobs.
- Wrap ComfyUI, and every other long media job, in your own MCP server that implements the MCP Tasks extension so a `tools/call` returns a durable taskId immediately instead of holding the connection open for eight minutes — the agent polls tasks/get, the task can move to input_required for an approval, and the handle survives a client restart, which is exactly the failure mode that kills naive video pipelines.
- Put one self-hosted LiteLLM proxy in front of every model call in the entire suite and issue a separate virtual key with its own monthly budget to each pipeline, so model routing, spend caps, fallbacks and the emergency kill switch all live in one container rather than being scattered across a dozen scripts.
- Exploit prompt caching aggressively by structuring every prompt as [stable brand prefix][volatile task]: write the brand book and product knowledge once with a 1-hour cache_control breakpoint at 2x input price, then pay 0.1x on every subsequent post that day — and never edit a byte of that prefix mid-session, since any change invalidates the cache.
- Route work by model tier deliberately: Haiku 4.5 ($1/$5 per MTok) for hashtag expansion, alt text and metadata, Sonnet 5 ($2/$10) for the bulk of caption and copy generation, Opus 5 ($5/$25) only for strategy, angle generation and anything where brand voice subtlety in Turkish actually matters — and push every non-interactive job (a whole month of content calendar drafts) through the Batch API for a flat 50% discount that stacks with caching.
- Instrument with OpenLLMetry so traces are plain OTLP conforming to the OpenTelemetry GenAI semantic conventions, then point them at self-hosted Langfuse (MIT core) if you can afford the four-service footprint of Postgres + ClickHouse + Redis + S3, or at Arize Phoenix locally if you cannot — the instrumentation decision is the one that must not be vendor-specific, since the backend is then swappable for free.
- Use Activepieces rather than n8n for connectors: it is MIT with no Sustainable Use License ambiguity, and every one of its 280+ pieces is exposed as an MCP tool, so your Claude agents call Instagram, LinkedIn and Drive directly instead of bouncing through webhooks — keep n8n as a fallback only if a specific connector you need exists nowhere else.
- Treat the visual builders as strictly disposable and never let brand logic live inside them: Flowise was archived read-only on 2026-08-13, which is the concrete demonstration that a workflow encoded as a JSON blob in someone else's database is a liability, whereas a SKILL.md in your git repo will still be readable and runnable in five years.
- If you outgrow shelling out to `claude -p` and want the command center and the pipelines in one TypeScript codebase, adopt the Vercel AI SDK v7 and its HarnessAgent API, which runs Claude Code as an agent backend behind the SDK's streaming primitives so a React approval UI wires up without you writing a protocol bridge — and add Mastra only if you additionally want typed workflows with checkpointed suspend/resume.
- For the two or three prompts you will run hundreds of times — Turkish caption generation and hook/angle generation — spend one weekend with DSPy optimising them against a labelled set of your own best-performing posts, then freeze the winning prompt into a SKILL.md rather than keeping DSPy in the runtime path.


### Riskler

- Licence traps are the biggest non-obvious risk in this stack: n8n's Sustainable Use License restricts you to 'your own internal business purposes', Restate is BSL-1.1 and explicitly not open source, the Inngest server is SSPL (only the SDKs are Apache-2.0), Arize Phoenix is Elastic License 2.0, Dify is Apache-2.0-plus-additional-conditions, ComfyUI is GPL-3.0, and Windmill's free Docker images carry proprietary internal-use-only terms — all fine for a personal system today, all potentially blocking the moment 'not a product to sell (for now)' stops being true.
- The Claude Agent SDK is governed by Anthropic's Commercial Terms rather than an open-source licence, and the docs explicitly forbid using claude.ai login or subscription rate limits to power a product, forbid 'Claude Code' branding, and reserve the right to change behaviour — so budget for API-key billing and accept that this one layer is not portable, which is precisely why the knowledge should live in portable SKILL.md files rather than in SDK-specific code.
- Checkpointing is not durable execution: LangGraph, CrewAI and ADK save state between steps but a crash mid-node replays the node, so a video generation or a social post can be issued twice — every external side effect in a media pipeline needs an idempotency key or a dedupe table regardless of which framework you pick.
- Self-hosted Langfuse requires Postgres, ClickHouse, Redis/Valkey and S3-compatible storage all running in UTC, which is materially more operational surface than the rest of the recommended stack combined; underestimating this is the most likely way a solo operator ends up with an observability layer that is down exactly when they need it.
- Automated posting to Instagram, LinkedIn and X is governed by each platform's own API terms and rate limits, not by the automation tool's licence — unofficial or scraping-based posting integrations risk account suspension, and platform API access, pricing and regional availability from Turkey can change without notice, so verify each channel's current developer terms before wiring an agent to publish unattended.
- Free-tier and aggregator model routes (OpenRouter free models in particular) frequently reserve the right to log and train on prompts, which means unreleased campaign material, client information or unannounced product details must never be routed through them — segment your LiteLLM virtual keys so cheap routes physically cannot see confidential context.
- Agent-driven code execution is a live security exposure in exactly the places this project touches: smolagents' LocalPythonExecutor is documented as not a sandbox, ComfyUI custom nodes are arbitrary third-party Python, MCP tool descriptions from untrusted servers are explicitly untrusted input per the spec, and `claude -p` without `--bare` executes hooks and MCP servers from a repository's .claude/settings.json in folders you never trusted.
- Ecosystem churn is faster than a solo operator can absorb: Flowise archived on 2026-08-13, AG2 split its v1.0 from AG2 Classic, ADK 2.0 shipped breaking changes from 1.x, the Agent SDK removed its experimental V2 session API in 0.3.142, and the OTel GenAI conventions moved repositories — pin versions, prefer components with permissive licences and plain-file data formats, and re-verify any pricing or capability in this report against primary sources before it is more than a few weeks old.
