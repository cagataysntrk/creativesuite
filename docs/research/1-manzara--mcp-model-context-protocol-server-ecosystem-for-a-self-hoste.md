## Özet

MCP in August 2026 is in the middle of its biggest break since launch. The current spec is 2026-07-28 (previous: 2025-11-25), and it makes the protocol STATELESS: no initialize handshake, no Mcp-Session-Id, no protocol sessions. Every request self-describes via `_meta` (protocolVersion, clientCapabilities, clientInfo); servers MUST implement `server/discover`. Server-initiated calls (roots/list, sampling/createMessage, elicitation/create) are replaced by Multi Round-Trip Requests (MRTR): a server returns `resultType:"input_required"` with `inputRequests`, and the client retries the original request with `inputResponses`. Roots, Sampling and Logging are all formally DEPRECATED (12-month minimum window), as is HTTP+SSE transport and OAuth Dynamic Client Registration (superseded by Client ID Metadata Documents). SSE resumability/Last-Event-ID is gone; `subscriptions/listen` replaces the GET stream and resources/subscribe. List results now carry `ttlMs`/`cacheScope` so gateways can cache, and `Mcp-Method`/`Mcp-Name` headers let proxies route without parsing bodies. Extensions became a first-class framework: `io.modelcontextprotocol/tasks` (async long jobs), `io.modelcontextprotocol/ui` (MCP Apps — sandboxed HTML UIs served under `ui://`, shipped Jan 2026), plus auth extensions (client-credentials, Enterprise-Managed Authorization). The official registry (registry.modelcontextprotocol.io) holds roughly 10k servers. Practically every vendor a creative command center needs now runs a hosted OAuth remote server — Notion, Linear, Airtable, Buffer, Blotato, Ayrshare, Replicate, Recraft, Runway, Freepik, PostHog, Supabase, Cloudflare, Stripe, Sentry, GitHub, Figma, Canva, Google Cloud/Workspace. The gaps are exactly where the money is: no official Meta/Instagram, TikTok, LinkedIn or X MCP; those still route through Postiz (AGPL, self-hostable), Blotato or Ayrshare.

**MCP Specification 2026-07-28** — Breaking: initialize/initialized removed; Mcp-Session-Id removed; ping, logging/setLevel, notifications/roots/list_changed removed; SSE resumability (Last-Event-ID) removed; resources/subscribe replaced by subscriptions/listen; all results carry resultType ('complete' | 'input_required'); resource-not-found error moved -32002 → -32602; error codes -32020..-32099 reserved for the spec. DEPRECATED: Roots, Sampling, Logging, HTTP+SSE transport, OAuth DCR (RFC7591), includeContext 'thisServer'/'allServers'. 12-month minimum deprecation window.

**MCP Multi Round-Trip Requests (MRTR) pattern** — Elicitation still exists conceptually but `notifications/elicitation/complete` and the URL-mode `elicitationId` were removed; servers correlate across retries via their own identifier in `requestState`. Sampling (asking the client's LLM) is deprecated — call an LLM provider API directly from your server instead.

**MCP Apps extension (io.modelcontextprotocol/ui)** — Rendered in a sandboxed iframe (web hosts use a double-iframe proxy pattern). CSP is built from declared `connectDomains`/`resourceDomains`/`frameDomains`/`baseUriDomains`; default denies all external access. Views act as MCP clients over postMessage JSON-RPC: tools/call, resources/read, ui/message, ui/open-link, ui/request-display-mode (inline/fullscreen/pip), ui/update-model-context. Tool `visibility: ["app"]` hides a tool from the model but exposes it to the UI. Host support varies — verify your client renders MCP Apps before betting on it.

**MCP Tasks extension (io.modelcontextprotocol/tasks)** — Moved out of core in 2026-07-28. Blocking `tasks/result` removed in favour of polling `tasks/get`; `tasks/list` removed; servers may return task handles unsolicited. Roadmap flags retry semantics and result-expiry policies as still-open questions.

**MCP auth extensions (ext-auth): OAuth Client Credentials + Enterprise-Managed Authorization** — Core auth in 2026-07-28 hardened: RFC 9207 `iss` validation is MUST-validate-if-present; DCR clients must send `application_type`; credentials MUST be keyed by issuer and never reused across authorization servers; Client ID Metadata Documents (CIMD) now preferred over DCR.

### Öneriler

- Target the 2026-07-28 spec for the MCP servers you write yourself (brand system, product knowledge, business strategy, asset library) using the TypeScript SDK v2 or FastMCP, but assume every third-party server you connect is still on 2025-11-25 — build your client layer to negotiate both, and never depend on Roots, Sampling or Logging, all three of which are now formally deprecated with a twelve-month removal clock.

### Riskler

- The 2026-07-28 spec is a hard break: no initialize handshake, no Mcp-Session-Id, no SSE resumability, and server-initiated requests replaced by MRTR. Most third-party servers in the registry have NOT migrated, so for the next several months you will be running a mixed-version fleet and your client must handle both — budget real engineering time for this, not an afternoon.
- Roots, Sampling and Logging are deprecated with a minimum twelve-month window. Any architecture that relies on a server asking the client's LLM to generate text (Sampling) needs rewriting to call an LLM provider API directly from the server.
- Prompt injection through MCP is unsolved, and a creative pipeline is unusually exposed: the agent reads competitor sites, comments, DMs and scraped social content, then calls tools that publish under your name. Stripe's own docs warn about combining their MCP with other servers. Never let a server with publishing rights share a context with a server that ingests untrusted web content.
- Tool poisoning and rug pulls: a community server can ship benign tool descriptions, get approved, then change them in a later version. Snyk Agent Scan does not explicitly cover rug-pull detection, so version-pin every server and rescan after upgrades.
- Community media servers (fal, Gemini/Veo, ComfyUI) hold your API keys and, in several cases, execute arbitrary code — BlenderMCP has an execute_code tool and the richest ComfyUI MCP edits the live node graph. Both are effectively remote code execution paths into your machine.
- Confused-deputy and token-passthrough attacks are named explicitly in the spec's security-best-practices document. If you build any MCP proxy or gateway in front of your integrations, you MUST implement per-client consent storage, exact redirect_uri matching, single-use state values set only after consent, and you MUST NOT accept tokens not issued for your server.
- Slack's community MCP 'stealth mode' reuses browser session cookies (xoxc/xoxd), and X community servers offer SocialData.tools to 'bypass Twitter API limitations'. Both are ToS gray zones that can get the underlying account suspended — a serious risk when the account IS your brand.
- Browser-driving MCPs (Playwright, Chrome DevTools) used against logged-in social UIs constitute automation-by-browser, which nearly every platform's ToS forbids. Use them for your own sites and for rendering, never for posting.
- Figma's MCP is free only during beta, is announced as becoming a usage-based paid feature, and restricts connections to clients on Figma's approved MCP Catalog — meaning your own custom command-center app may simply be unable to connect. This is the sharpest lock-in risk on the list; Penpot is the mitigation.
- AGPL-3.0 appears on Postiz, Firecrawl's core and Metabase OSS. Personal and internal use is fine, but if you ever expose a modified version as a network service to other people, you must publish your modifications. n8n's Sustainable Use Licence is not OSI open source and forbids offering it as a hosted service to third parties.
- Vendor MCP surfaces churn faster than the protocol: Recraft already deprecated its local server for a remote one, Runway removed gen3a_turbo and gen4_aleph from the API on 2026-07-30, Linear retired its SSE endpoint, and thirteen former MCP reference servers were archived. Any integration you hardcode will need maintenance within months.
- The official MCP Registry is still labelled preview with possible breaking changes and data resets, and its API froze at v0.1 — do not build automatic install flows that assume registry stability.
- Google's entire Workspace MCP fleet (Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat, People) is Developer Preview, as are several Google Cloud MCP endpoints. Expect breaking changes and possible enrolment requirements on what would otherwise be the cheapest deck-generation path available.
- Turkey-specific availability, payment methods and regional restrictions were NOT verifiable from primary documentation for any of the paid media vendors (Recraft, Runway, ElevenLabs, Freepik, Blotato). Verify before you build a pipeline around one.
- Turkish-language output quality is untested across the board — generative image models rendering Turkish diacritics (ç, ğ, ı, İ, ö, ş, ü) in text overlays is a known weak point. Rendering text from your own HTML templates via Chrome DevTools MCP sidesteps this entirely and is the safer default for any graphic with copy on it.
