# Dima SaaS Product Launch V2

HyperFrames-native 16:9 product launch film.

Direction:
- modified product UI rather than abstract tech imagery,
- bold typography,
- clean high-energy SaaS editing,
- music-synchronized scene architecture,
- no generative AI video,
- no copied reference audio or frames.

Music:
- if `ELEVENLABS_API_KEY` is configured, the repo's ElevenLabs Music engine creates a new instrumental from an original high-level brief;
- otherwise a deterministic 120 BPM original electronic score is synthesized locally.
- both paths are normalized and muxed into the final master.
